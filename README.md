# Once Upon Another Time — Book One (Pass 24 RC1)

Ages 8–12 · portrait-first interactive fairy-tale adventure.

## Install on GitHub Pages
Extract this ZIP. Upload the extracted files and folders to the root of a GitHub repository. Keep `index.html`, JavaScript files, `styles.css`, `assets/`, `audio/`, `manifest.webmanifest`, `service-worker.js`, and `privacy.html` together. In repository Settings > Pages, choose the branch and `/ (root)` directory, then verify the published URL on an actual phone.

### Saves and offline use
Export a game backup from Settings > Backups before replacing an older version. Staying at the same site URL normally keeps your local save. Moving domains or devices requires importing an exported backup. The PWA caches game resources after first load; confirm offline behavior on your real device after it is installed.

### Family privacy
No login, chat, ads, or analytics code is bundled. Local save data remains on the device unless the player exports it. The hosting provider may log routine network information. See `privacy.html`.
